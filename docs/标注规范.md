# 标注规范

## 一、检索评测集标注（双人标注 + Kappa 一致性）

### 任务
给定评价型查询，从知识库中标注所有"直接支撑该查询"的条款块（chunk_id）。

### 判定标准
- **相关**：条款直接规定该查询涉及的行为要求、义务或处罚（如查询"披露时限"→ 第二十一条）；
- **部分相关**：条款间接相关（定义、原则性条款）→ 标注为相关，但在 comment 列注明；
- **不相关**：仅主题相近但无法直接支撑评价结论。

### 流程
1. 标注人 A、B 独立标注 `retrieval_queries.csv` 的 `relevant_chunk_ids` 列（另存为 `*_A.csv` / `*_B.csv`）；
2. 计算 Cohen's Kappa：`src/metrics/stats.py` 的 `cohens_kappa(a_labels, b_labels)`，
   将每个 (query, chunk) 对展开为 0/1 标签后计算；
3. Kappa ≥ 0.6 接受，< 0.6 讨论分歧、修订规范后重标；
4. 分歧条款由第三人仲裁形成最终标注。

## 二、生成评价人工核验

### 引用忠实度核验（30 条随机抽样）
对每条评价中的引用标注 `citation_supported`：
- 1 = 引用的法规/条款确实存在于检索结果且内容支持该论点；
- 0 = 引用不存在、张冠李戴、或条款存在但内容不支持论点。

### 事实错误核验
`fact_error`：1 = 评价中出现与年报事实材料矛盾或凭空捏造的事实；0 = 无。

### 字段
见 `data/annotation/generation_annotation_template.csv`：
`sample_id, dimension, mode, annotator, citation_supported, fact_error, comment`

## 三、一致性报告要求

论文中需报告：标注人数、独立标注比例、Kappa 值、仲裁机制。
示例表述：两名标注者对全部检索查询独立标注，初始一致性 Cohen's Kappa = 0.82，
分歧条款经讨论达成一致后形成最终评测集。
