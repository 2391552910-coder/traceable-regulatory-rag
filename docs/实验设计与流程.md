# 实验设计与流程（论文实验部分底稿）

## 1. 研究问题

- **RQ1**：条款级切分 + 维度路由的混合检索能否提升监管法规检索的召回与排序质量？
- **RQ2**：注入法规依据并施加引用约束（本方法）相比无 RAG / 朴素 RAG，能否提升评价的忠实度、事实覆盖度与引用可信度？
- **RQ3**：条款级切分、维度路由、融合权重三个组件各自的贡献多大？
- **RQ4**：本方法在多大程度上降低"引用不存在的法规"这一幻觉行为？

## 2. 数据集构建

### 2.1 监管知识库
- 来源：国家法律法规数据库、中国证监会官网公开发布的监管规则、行政处罚决定书、典型案件通报；
- 规模：已完成 **315 篇**（regulation 84 / penalty 212 / announcement 19，条款级切分 7,840 块），
  采集流程见《知识库采集说明.md》；
- 切分：条款级（本方法）与 512 字滑窗（对照），字段见 `data/knowledge_base` 格式说明；
- 维度标注：每篇文档标注关联自律维度 D1-D4（弱标签），供维度路由检索使用。

### 2.2 检索评测集
- 构建方式：围绕四维度指标体系设计 40 条评价型检索问题（每维度 10 条，
  如"年报披露时限的监管要求"），弱监督预标 + 双人独立复核标注相关条款（chunk_id），
  不一致处协商仲裁；
- 一致性：报告双人标注 Cohen's Kappa（`src/metrics/stats.py`），Kappa > 0.6 方可采用；
- 格式：`data/annotation/retrieval_queries.csv`。

### 2.3 生成评测样本
- 样本：30-50 家 A 股上市公司年报（不同行业/市值），抽取事实由第四章系统抽取模块产出
  （或按 `data/companies/*.json` 格式人工构造）；
- 每家公司四个维度各生成一条评价，共 120-200 条评价样本。

## 3. 实验设置

### 3.1 检索实验（对应 RQ1/RQ3）
| 配置 | 说明 |
| --- | --- |
| BM25-only | jieba 分词 BM25，k1=1.5, b=0.75 |
| Dense-only | BGE-M3 余弦相似度 |
| Hybrid | 双路归一化加权融合，w=0.7 |
| Hybrid+Routing（本方法） | 维度路由子库检索 + 维度化查询模板 |

指标：Recall@5、MRR、nDCG@5（`experiments/02_retrieval_evaluation.py`）。

### 3.2 生成实验（对应 RQ2/RQ4）
| 模式 | 检索注入 | 引用约束 |
| --- | --- | --- |
| no_rag | 无 | 无 |
| naive_rag | 有（同本方法检索结果） | 无 |
| ours（本方法） | 有 | 强制标注【依据：《X》第Y条】+ 禁止引用检索结果外条文 |

- 每条评价重复生成 3 次取均值（温度 0.2）；
- 指标：
  1. **引用忠实度**（citation accuracy）：模型引用与检索命中的对齐比例（证据对齐机制，人工复核子集 30 条）；
  2. **LLM-as-judge**：faithfulness / coverage / professionalism 三维 1-5 分；
  3. **幻觉率**：正文引用中未出现在检索结果内的比例（no_rag 基线的理论上限）；
- 显著性：Wilcoxon 符号秩检验（配对），报告 p 值与效应量（`experiments/05_statistical_tests.py`）。

### 3.3 消融实验（对应 RQ3）
- 切分策略（clause/window）× 维度路由（on/off）；
- 融合权重 w ∈ {0.3, 0.5, 0.7, 0.9}；
- 脚本：`experiments/04_ablation_study.py`。

## 4. 可复现性

- 固定随机种子 42；模型版本与调用日期在论文中声明（deepseek-chat）；
- 开源对照模型：Qwen2.5-72B-Instruct 复跑主实验，验证结论不绑定单一商用模型；
- 评测代码、标注数据与提示词模板全部随仓库开源。

## 5. 预期实验结论（待数据验证后改写为实际结果）

1. 条款级切分使含条款号的可溯源块占比达到 100%，相比滑窗切分显著提升引用定位精度；
2. 维度路由混合检索的 Recall@5 与 nDCG@5 优于单一检索与全库混合检索；
3. 引用约束 + 证据对齐显著提升 judge 忠实度分（p<0.05），引用忠实度接近 1.0，幻觉率显著低于基线。
